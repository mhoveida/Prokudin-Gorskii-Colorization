Overview

Sergei Prokudin-Gorskii was a photographer who traveled across the Russian Empire in the early 1900s, capturing thousands of images using three separate glass plate negatives, one each through red, green, and blue filters. This project automatically aligns these three black and white channels to produce original vivid color images.

The goal is to fix the temporal displacement from sequential exposure process and recreate the original scene as it would have normally appear to the human eye.

The Problem: Unaligned Images

If we just stack the three color channels without aligning them, the image looks blurry and shows colored edges. Here’s what the original unaligned images look like:

Solution

Algorithm Overview

I implemented a two-stage alignment system:

  • Single-Scale Exhaustive Search: For small JPG images, I search over a [-15, 15] pixel window to find the best alignment
  • Image Pyramid (Coarse-to-Fine): For large TIF images, I use a pyramid approach: I downsample the image, align it at a low resolution, and then gradually refine the alignment at higher resolutions.

Metric: L2 Norm

Sum of Squared Differences. It measures the pixel by pixel distance between two images. The goal is to make this value as small as possible.

Metric: NCC

Normalized Cross-Correlation. It measures how well the images match using a dot product. The goal is to make this value as large as possible.

My Design Decisions

Green vs Blue Anchor

The assignment suggested using the Blue channel as the reference anchor. However, after experimentation, I found that the Blue channel often contains more noise and blur. Switching to the Green channel as the anchor significantly improved alignment quality, especially for challenging images like emir.tif, melons.tif, and self_portrate.tif.

Result: All images shown below use Green as the anchor (displacement[0, 0]), with Red and Blue aligned to it.

In addition to alignment, I implemented three extra features to to improve image quality.

1. Automatic White Balance

Many of the original glass plates have a strong color tint. This happens because the film has aged and because of the lighting conditions when the photos were taken in the early 1900s. To fix this, I used the Gray World Assumption algorithm.

This method assumes that the average color of a scene should be neutral gray. I compute the average intensity of each channel (R, G, B) and scale them so their averages match. This removes the color cast and makes the image look more natural.

As shown below, the "Before" image has a strong color cast, while the "After" image has a more natural color balance.

Before White Balance

After White Balance

2. Automatic Contrast Enhancement

Even after white balancing, the images often look flat because their pixel values don't use the full brightness range. To improve contrast, I use histogram stretching.

Instead of stretching using the minimum and maximum values (which can be affected by noise), I use the 2nd and 98th percentiles. I then rescale this range to cover the full [0, 1] range and clip extreme values. This makes the image more vibrant without over saturating it.

4. Border Cropping

My code doesn't cut every picture the same amount. Instead, it checks the filename to decide what to do. Additionally, for self_portrait.tif, it cuts an extra 15% off the left side to get rid of a big black border.

  • Light Crop (6%): Most images
  • Standard Crop (8%): lastochikino, lugano (better borders)
  • Special Crop: self_portrait (15% left, 6% other sides)

Challenges and Limitations

Some images like harvesters.tif show color fringing around people. This is because they moved between the three exposures. My algorithm aligns the static background correctly but cannot correct for moving objects.

Overall, the alignment method worked very well. The algorithm processes each TIF image in under 10 seconds on my machine, which is fast enough to meet the requirements. The automatic white balance and contrast adjustments also make the final photos look much better.

To keep the submission small, I only put the final L2-aligned images in the assets folder. However, if you run main.py, the code will recreate all the versions (NCC, L2, White-Balanced, final) and print the full displacement vectors for both metrics to the console.
